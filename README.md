PLFC 2026 Data is a static AGM discussion dashboard for Point Lookout Fishing
Club. It turns a snapshot of club activity, systems, challenges and possible
next steps into an easy browser view.

## Public page

- [Open the PLFC AGM dashboard](https://auraofintelligence.github.io/PLFC_2026_Data/)

## What is here

`index.html` contains the complete dashboard and its embedded data. The page
includes views for:

- a timeline and vision progress;
- social reach and systems built;
- shortcomings and proposed remedies;
- grant readiness and skills capacity;
- immediate needs; and
- a simple comparison with other island clubs.

## Open locally

Open `index.html` in a browser. No build step, login or backend is required.

## Status and boundaries

This is a simplified discussion snapshot, not the club's canonical records,
audited accounts, approved minutes, live analytics or a judgement of people.
Dates, follower counts, grant status, comparisons and proposed actions can go
stale and should be checked with the committee and their source records before
reuse or publication elsewhere.
